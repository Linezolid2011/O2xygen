# O₂xygen

世界观构造工作台 —— 面向小说设定的实时恒星系统物理沙盒。
版本见 `docs/version.txt`(唯一真源,ADR-0003)。

> **分支说明 —— 本分支为 branch 2(`0.4.x`)**:基于 0.4.x 做 bugfix 与 UI 打磨,
> 保持 0.4.x 的功能面不变。0.5.x 的新特性开发(ExoPlaSim + SBDART 接入)在
> branch 1 上进行,不进入本分支。

与常见的"开普勒推演"类工具不同,O₂xygen 的轨道是**实时 N-body 积分**
算出来的(ADR-0015):恒星会按 MIST 演化轨迹老化掉质量,行星轨道随之
真实膨胀;小天体的瞬时偏心率会因恒星摄动产生数十年量级的 Kozai 型
振荡。每条天体身后的"烟雾"只是客户端最近收到的真实位姿历史;
高速欠采样时诚实显示折线,服务器不再为显示反向积分(ADR-0034)。

**世界即存档(ADR-0016)**:每个世界是一个 `[worldname].oxygen` 文件——
扁平天体(仅恒星/非恒星)+ 笛卡尔初始条件 + 时间原点。恒星只保存
MIST 自变量(初始质量/[Fe/H]/年龄),当前质量/半径/光度/温度均由
MIST 运行时求值,不另存副本(ADR-0022/0026)。schema v2 另存权威逃逸风
历史账本,它依赖真实动力学事件,不是可重复计算的 MIST 输出(ADR-0030)。
schema v3 另存非恒星大气输入与命名观察点(只含天体名/经纬度;ADR-0038)。
没有层级,没有"卫星"身份;轨道关系从动力学中涌现,以**相对除自己以外
的系统质心**的瞬时根数形式被观测(ADR-0022:根星概念退役)。显示、网格、
标签与烟迹则统一使用**固定世界原点**,不再随质心移动(ADR-0035)。
时间以"自原点经过的秒数"计量,显示为 yyyy-mm-dd From origin。

**推演不可逆(ADR-0018)**:时间只通过"推演"流动——设置时长与速度后,
世界被实时积分向前推进,**存档每 0.5 秒自动改写为新 epoch 的初始
条件**(恒星年龄同步推进)。正确备份逻辑是推演前"另存为"。推演期间
时间轴显示真实标度与进度(不可拖动),左下角播放键担任暂停/恢复,
暂停时左上角按钮变为红色"取消"(确认后停表并**回滚到上次自动存档**,
内存与存档永不背离);非推演模式时间轴完全惰性(刻度 NaN)。
一切查询(含显式时刻)都在检查点恢复副本上求值,任何请求都不会拨动
活时钟(ADR-0019)。**渲染由服务器位姿驱动(ADR-0021/0034)**:SSE 推送
权威位姿(~60 Hz);客户端只保留最近 240 个位姿画烟迹,不做任何轨道计算,
初始/刷新无烟迹,暂停不追加,回退或重连清空。

## 功能

- **多世界**:`data/worlds/[worldname]/[worldname.oxygen]` 存档,UI 头部
  下拉切换、另存为,首启自动物化内置白玫瑰;每个世界有独立资源目录。
- **实时积分 + 推演**:rebound IAS15(默认)/ WHFast;推演债额 pacing
  (实测速率与配置值分毫不差)、块级步数预算、外部时钟移动检测、
  温度类查询非破坏化(副本采样,永不拨动活时钟)。
- **恒星演化**:MIST v1.2(MESA r7503)轨道空间双线性插值,风损质量
  绝热耦合进积分;MIST III 白矮星冷却轨迹按初始质量/[Fe/H]/总年龄求值;
  仅质量超出 MIST III 覆盖的 WD 使用 WDCool 后备(ADR-0028);
  WDCool 的质量与形成年龄由 MIST 网格末点交接,而非独立输入。
  恒星随推演真实老去(质量/半径/温度/光度同步)。
- **开放天体系＋逃逸风守恒**:聚合记录逃逸风的质量、动量、固定原点角动量
  与一阶质量矩;风事件间弹道传播,天体＋风封闭守恒,剩余天体质心允许移动。
  存档/检查点/查询/取消回滚使用同一账本;人工改参开启新守恒基准(ADR-0030)。
- **行星结构**:Zeng+2016 PREM 质量-半径拟合、CMF 推断、Maclaurin 扁率、
  n=1 多方球分层。
- **自转与潮汐**:存档记录自转轴/角速度/相位;恒定时间滞后平衡潮
  在演化中交换自转与轨道角动量;结构演化以无力矩 `I*omega` 闭合,
  轨道＋自转＋风的总角动量守恒(不含洛希极限与撕裂)。
- **统一外观**:恒星颜色由当前 Teff 黑体转换,非恒星保存线性工作 RGB
  (UI 为 sRGB 0–255);目录圆点、球体、烟迹共用同一颜色。非恒星 3D
  材质按各恒星方向 Lambert 受光,昼/夜半球清楚可分。非恒星编辑器同时
  编辑质量、反照率、颜色、自转和大气(ADR-0040)。
- **天文坐标**:日心 ICRS/J2000 世界位置、绝对历元与固定朝向四元数
  入档;自动存档同步推进历元,并用于真实星场重投影。
- **查看/编辑/实况模式**:查看模式可查询和推演;实况模式不推进时钟,从
  存档中的命名观察点显示本地天空、球面地面、真实星场、系统天体与大气。
  左侧管理观察点(只保存所属天体和经纬度),右侧显示温度、多星照明、
  高度/方位和掩星。非恒星编辑器支持自转相位与大气输入;大气使用球壳
  光学厚度、RGB 相函数与二至四阶 Monte Carlo 多次散射,WebGL2 显示,
  无需 Qt/C++;高阶角分布为方位平均近似,不是气候求解器(ADR-0038)。
  编辑模式提供恒星草稿编辑器,支持 MIST 种子、自转及覆盖外 WD 的 WDCool 输入;当前属性只读,
  可在保存前预览生命周期与损失量,年龄轨道按 MIST EEP 分段并支持拖动;
  保存才入档,退出不保存;编辑模式可用“对齐”把剩余天体质心纯平移到
  世界原点并保存,速度、质量、年龄、自转及风账本均不重置(ADR-0031)。
  双栏“添加天体”支持 MIST 恒星/非恒星、绝对位置速度与速度箭头、单母星
  完整开普勒轨道预览;确认只保存绝对 p/v,不保留层级(ADR-0036)。预览球体
  使用真实半径并显示名称标签,轨道以母星居中、直接放置以新天体居中;
  新恒星和恒星母星另显示 Teff 着色的光晕;半长轴单位可用同款滑块在
  AU 与 km 间切换,质量也支持 kg;质量/半径/半长轴接受 `1.23e4` 科学计数法;
  轨道预览另以红色状态栏提示双向刚体洛希极限问题。
- **温度管线**:三种平衡温度体制 + 反照率,温度表从当前时刻向前采样。
- **WebUI**:标准库 http.server + SSE 推流 + Three.js + uPlot,无构建步骤;
  服务器权威位姿、客户端零物理的固定容量烟迹环形缓冲区、**Hipparcos
  真实星场**(任意天体位置/历元的视差与星等)、相对系统质心的瞬时
  根数面板、选中即跟随相机、独立结构/温度计算面板。系内恒星使用
  Planck→CIE 黑体颜色,背景星共用 B−V 颜色映射与视星等光通量;实况以
  线性 HDR 合成和天空亮度驱动的显示适应避免白昼满屏亮星(ADR-0039)。

## 运行

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e . rebound
.venv/Scripts/python server/app.py        # http://127.0.0.1:8501
```

也可运行 `run.cmd`。服务运行中按 Ctrl+C 会询问“是否终止运行？ [Y/n]”;
输入 Y/yes 或直接回车退出,n 继续运行。

运行期依赖只有 **numpy + rebound** 两个 PyPI 包(ADR-0020):HTTP 层是标准库
`http.server`,标量求根/求极值是 `src/o2xygen/optimize.py` 的手写实现;
测试用 pytest(仅开发期)、UI 烟测用 playwright(仅开发期)。

测试(156 项,含公开参照标定、风损封闭守恒、表面坐标/大气、外观与迁移回归):

```bash
.venv/Scripts/python -m pytest
```

## 数据

**MIST 恒星网格随仓库分发**(0.1.1 起,用户裁定:下载之苦不转嫁):分卷
压缩包位于 `.data/MIST-compact/`(每卷 ≤64 MB,避开 GitHub 单文件
100 MB 限制;原始包约 107 MB × 2)。首次启动时程序自动拼接分卷并解压到
`.data/MIST/`(纯 Python tarfile,解压产物与解析缓存被 gitignore,
压缩卷保留不删)。MIST、WDCool、Hipparcos 等参考资料仍在 `.data`。
世界存档(`*.oxygen`)是独立用户内容,默认存于
`data/worlds/[worldname]/[worldname.oxygen]`(环境变量 `O2YGEN_WORLDS_DIR`
可覆盖),不进仓库;每个世界目录也可存放以后由该档派生的高成本缓存。
旧平铺存档可用 `scripts/migrate_world_layout.py --apply` 备份并迁移。

Hipparcos 验证数据位于 `.data/hip2000/`(不入库):`hip_main.dat` 为
J1991.25 原始观测历元,生成的 `hipparcos_*.js` 为 J2000;可用
`scripts/verify_hipparcos_epoch.py` 复验两者的逐星等价性。
运行时星场使用随仓库分发的 `.data/hipparcos.npz`(112,846 星,3.11 MB),
无需保留原始表或旧 skycalc 项目。MIST III WD 冷却使用随仓库分发的
`.data/mist3_wd.npz`(199 轨道,20.81 MB),无需原始 879 MB 下载包。
质量超出 MIST III 的 WD 另用随仓库分发的 `.data/wdcool.npz`
(46 序列,0.34 MB,Bédard et al. 2020)。

## 仓库结构

```
src/o2xygen/   物理内核(纯 Python,可独立使用;optimize.py 为手写 Brent/黄金分割)
server/        标准库 HTTP 服务(Workspace = 活积分器 + 恒星演化耦合)
web/           原生 ES modules 前端(无构建)
tests/         156 项标定、守恒与交互验收测试
docs/          CHANGELOG / ADR 档案(decisions.md)/ 重建笔记(RECON.md)
shots/         无头 Chrome 截图存档(UI 迭代留痕)
scripts/       shot.py(截图)/ dbg_scene.py(场景调试)/ repair_world.py(存档修复)
```
