# Changelog

本项目自 0.0.0 起独立定名 **O₂xygen**(徽标 O 下标 2,「xygen」上标)。此前的开发
以好友的闭源应用「ORBIT」(世界观构造工作台) 为参照系进行干净室重建;自本版本起,
O₂xygen 作为独立产品演进。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/),
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### 破坏性变更(ADR-0016):世界即存档

- **多世界 + 文件存档**:每个世界是 `[worldname].oxygen`(JSON,format/
  version 字段);服务端 `WORLDS_DIR` 管理,UI 头部下拉切换、另存为;
  首启自动物化内置白玫瑰。
- **扁平天体模型**:类型仅 恒星/非恒星;层级与"卫星"身份删除;内部状态
  = 笛卡尔初始条件 (mass, pos0, vel0, SI)。开普勒根数降级为放置工具
  (UI 输入根数 → 换算状态向量)。新增 test_world.py 存档往返测试。
- **原点语义**:存档指定原点天体;渲染坐标 = 绝对坐标 − 原点坐标(烟雾
  轨迹逐采样原点相对);瞬时根数相对原点计算——卫星相对恒星呈带摆动
  类行星根数(扁平化的诚实观测量)。
- **时间原点**:内部为"自原点经过的秒数";显示换算 yyyy-mm-dd From
  origin(均匀历:365.25 天/年、12 等分月,纯显示约定)。
- **恒星种子防腐蚀**:存档存初始质量;mini_msun 在载入时钉死,MIST 风损
  演化不再污染跨存读循环的种子;恒星物性(质量/半径/温度/光度)全部由
  存档种子 + MIST 在 settle 时重建。
- dt 默认值改为成对动力学时标估计(sqrt(d³/G(M+m))/40),不再依赖根数。
- **显示尺寸 = 物理尺寸(ADR-0017,用户裁定)**:渲染球半径即 body.radius_m,
  无放大/基线/钳制(ADR-0011 废止)。判定记录:"卫星轨道画进行星球"是
  显示尺寸与物理尺寸脱钩所致——物理轨道 0.01 AU 为两星物理半径之和的
  45 倍、0.27 r_Hill,预设合法。配套可用性补丁:不可见拾取代理球、
  恒星光晕小下限、相机近平面自适应、聚焦最小距离放宽至 2e-4 AU。
- **恒星演化补齐半径与有效温度**(0.0.1 之后):演化耦合除质量/光度
  外现写回 radius_m 与 teff_k;`/api/state` 新增 `stars` 实时物性字段;
  前端按首个快照为基线缩放恒星球并随 Teff 改色(1.29 M☉: 1.26 Gyr 时
  0.93e6 km/6478 K → 5.0 Gyr 时 6.0e6 km/4623 K,半径 6.5 倍)。

## [0.0.1] - 2026-11-15

首个公开发布。相对 0.0.0 的全部增量如下(0.0.0 为内部基线,含开普勒内核、
WebUI 初版与 26 项标定测试,此处不重复罗列)。

### 物理内核

- **实时 N-body 积分取代解析开普勒传播**(ADR-0015):rebound 后端
  (IAS15 默认;WHFast+17 阶校正子可选),fixed-dt + 检查点快照存档;
  支持时间轴双向拖动(时间对称查询)、绝热质量更新钩子、瞬时根数换算
  (显示用轨道根数变为导出量)。
- `kepler.py` 职责缩窄:初始状态构造、二体标定真值、快速估算。

### 服务端 / WebUI

- **全端点切到活积分状态**:新增 `GET /api/state`(位置/速度/质量/光度/
  瞬时根数);辐照、平衡温度、温度表全部沿积分路径采样;添加天体后重建
  积分器;页脚引擎徽标实时显示积分器与步长。
- **恒星演化耦合**:恒星在 epoch 即落到 MIST 轨道当前质量(与参照应用
  显示值一致),前向积分按年 cadence 绝热更新质量与光度——时间轴拉到
  1000 年可见真实轨道膨胀。MIST 网格二进制缓存(构建 22 s → 重载 1.5 s)。
- 前端快照驱动:服务端 800 ms 轮询 + 速度线性外推渲染;时间轴新增
  100 年 / 1000 年跨度(积分器性能内)。
- **烟雾轨迹取代轨道线**:每颗天体拖一条实际积分路径(窗口 = 0.4 ×
  瞬时周期,钳位 20–400 天),服务端单次回溯采样(约 60 ms/次快照),
  前端顶点渐隐渲染;向后拖动时烟雾自然延伸进负时间。flux/温度等管线
  内部调用跳过轨迹计算(温度端点 82 s → 0.24 s)。
- **渲染层真传播**:快照间隔内不再用线性外推(高速下标签沿切线飞出),
  改为客户端 N-body 速度 Verlet 迷你传播器(用快照全部 p/v/m,步长 =
  服务端 dt);实测 +20 天漂移 ~1e-4 AU,200 天/秒下标签-球体像素级贴合。
- **时间轴修复与增强**:刻度标签随跨度动态生成(修复静态 +10年 与
  1000 年跨度不同步);跨度与速度改为可输入框(跨度单位年,支持
  5000+ 年;速度任意值);滑块步长随跨度自适应;循环回绕时强制重新
  拉取快照,避免旧快照外推回绕点。
- 物理发现:白玫瑰卫星偏心率存在数十年量级的 Kozai 型自然振荡
  (e 0.15 → ~0.10),N-body 相对解析开普勒的差异化实证。

### 测试

- 新增 12 项积分验收(二体收敛/能量有界/绝热膨胀/检查点确定性/回扫
  一致性/层级稳定性/性能预算),全套 38 项通过。

## [0.0.0] - 2026-11-14

首个自冠名版本。包含以参照应用为蓝本的全部已重建功能与 WebUI。

### 物理内核 (Python 包 `o2xygen`,26 项标定测试全部通过)

- **层级开普勒模拟**:恒星/行星/卫星树形层级二体传播(牛顿法解开普勒方程),
  UTC 时间基,多星辐照求和 Σ L⋆/4πd²(S⊕ = 1361 W/m²),恒星自身辐照排除。
- **恒星演化 (MIST v1.2 / MESA r7503)**:392 条 EEP 轨道 ([Fe/H] = 0 / +0.25),
  轨道空间双线性插值(轨道内 log(age) 一维 + 跨质量一维,节点精确),
  跨 [Fe/H] 线性混合;`star_mdot` 取 |dM/dt| 为主序风损率;
  参照恒星 (1.29 M☉, [Fe/H]≈+0.10, 1.26 Gyr) 的半径/光度/温度/损失率全部
  复现至 <1‰~2%。
- **行星结构**:PREM 半经验 MR 拟合 R = (1.07−0.21·CMF)·M^(1/3.7)
  (Zeng, Sasselov & Jacobsen 2016;参照对象 Múspellsheimr 半径复现至 0.008%);
  Zeng(2019)-class 扩展近似;单极+离心重力;慢转近似与 Maclaurin 精确扁率;
  n=1 多方球分层剖面(层/半径范围/密度表)。
- **温度管线**:三种平衡温度体制(全球/昼侧/星下点)+ 灰温室因子;
  温度表采样(如 13 点/10 年)与温度曲线;标定:参照卫星 Αύρα 通量-温度对
  (861.46 W/m² ↔ 288.24 K)锁定昼侧体制 + 反照率 ≈0.09。

### WebUI (FastAPI + Three.js + uPlot,无构建步骤)

- 暗色三栏工作台布局:天体目录树、中央 3D 视图、右侧参数面板、底部时间轴。
- 3D:按有效温度着色的发光恒星、层级轨道线、行星环、自转、点选射线、
  浮动标签(选中角标)、轴向 gizmo、3D/2D 切换、**选中即居中**(平滑飞行相机,
  显示半径层级约束:子女轨道净空 + 母球比例上限)。
- 右侧面板:基础参数(实时辐照 + MIST 参数估算)、结构(CMF 滑杆 + 圈层
  SVG + 分层表)、大气(成分编辑器 + 气柱幂律参数)、温度表(uPlot 曲线 +
  当前时刻标记 + 跟随模式 + 采样表)、介绍(静态占位)。
- 时间轴:播放/暂停(空格)、天/秒调速、UTC 时钟(参照 epoch
  2026-11-18T19:00:25Z)、1 年/10 年跨度。
- 一键计算:结构与尺寸 → 大气与光学厚度 → 温度表,三阶段进度弹窗。
- 添加天体弹窗(名称/类型/环绕/半长轴/偏心率/质量)。

### 基础设施

- 无头 Chrome 截图迭代管线(Playwright,console/异常捕获):`scripts/shot.py`、
  `scripts/dbg_scene.py`。
- 物理解析与标定笔记见 `docs/RECON.md`;架构决策档案见 `docs/decisions.md`。

### 已知限制(后续版本)

- 无真实星空背景(等待与自研全天球渲染器集成);ExoMol Planck 均值与
  Clima 一维气候求解器未接入;LLM 叙事层未实现;无工程持久化;扁率选项
  仅慢转近似 + Maclaurin(ToF4/CMS 未实现);轨道根数不可在 UI 编辑。
- 0.0.1 新增已知限制:MIST 数据未随仓库分发(需自行放置,见 README);
  长跨度(>1000 年)下层级三体呈弱混沌,回扫与首次前进的瞬时根数
  可能差百分之几(物理真实,非缺陷)。
