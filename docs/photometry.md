# 光度、颜色与显示曝光

本文件区分**物理/星表输入、线性 HDR 显示合成、显示曝光**。它们不能混为一谈。

## 1. 颜色

- 系内恒星使用有效温度，按 Planck 黑体光谱积分到 CIE XYZ，再转换到线性
  sRGB。色匹配函数采用 Wyman–Sloan–Shirley 的 CIE 1931 解析近似。
  圆面固有辐亮度比例以 5772 K 为单位按 \(T^4\) 缩放；观察距离通过角直径
  进入几何，不再错误地用 \(1/d^2\) 衰减圆面本身的辐亮度。
- Hipparcos 背景星用 B−V 的 Ballesteros 经验温度 proxy，再走同一黑体颜色
  转换。B−V 并不唯一确定光谱型、温度或金属丰度，所以这不是逐星光谱拟合。
- 查看模式和实况模式使用同一个 `web/js/color.js`，没有两套手写调色板。
- 非恒星颜色以归一化 sRGB 三元组保存在 `extra.color_rgb`，与反照率分开：
  RGB 决定色相，反照率决定反射强度。目录圆点、3D 球体、烟迹和实况圆面
  都从这一份颜色转换，不另设固定蓝色。
- 非恒星 3D 材质按每颗恒星的当前方向做 Lambert 受光，并忽略恒星视角下
  被其他天体遮挡；夜侧使用很低的显示底光便于辨认圆面。昼夜明暗是显示
  几何，不是新增热模型或自发光。

## 2. 背景星的光通量

使用真实视星等关系：

\[
F_V/F_{V,0}=10^{-0.4m_V}.
\]

零等星的参考照度取 \(2.54\times10^{-6}\,\mathrm{lux}\)，太阳取
\(V=-26.74\) 与约 \(1.27\times10^5\,\mathrm{lux}\) 的参考照度，因此零等星
与太阳的光通量归一化比约为 \(2\times10^{-11}\)，不是它的倒数。

背景星按高斯点扩散函数显示，\(\sigma=60\) 角秒；其辐亮度参考量为
\(F_V/(2\pi\sigma^2)\)。屏幕像素大小是可读性辅助，不是恒星的真实角直径。

## 3. HDR 合成和颜色保持

实况使用两个半浮点目标：背景星和系统天体。大气散射、被大气衰减的星场和
系统恒星圆面先在线性空间合成，再统一显示：

\[
L(\lambda)=T_\lambda L_{\rm star}(\lambda)+L_{\rm scatter}(\lambda).
\]

系统圆面的透射率按 RGB 分通道计算，不再用平均透明度把恒星与蓝天做普通
alpha 混合。tone mapping 用共享亮度因子：

\[
Y'=1-\exp(-EY),\qquad RGB'=RGB\times Y'/Y,
\]

再做同因子色域压缩与 sRGB gamma。它避免 RGB 各自饱和成白色。

## 4. 白天为什么不再满屏亮星

背景星使用上面的光通量，而不是旧的 `clamp(1.25-0.1*mag)` 亮度斜坡。
显示曝光由当前天顶天空亮度估计驱动：

\[
E=8a\,\operatorname{clamp}\!\left(\frac{0.015}{\max(L_{\rm sky},10^{-10})},
1,2000\right),
\]

其中 \(a\) 是存档的显示曝光参数，\(L_{\rm sky}\) 由当前恒星方向、
光谱近似和同一光学表估计。白天降低显示灵敏度，弱星自然淹没在天空亮度中；
夜间提高显示灵敏度。没有“白天隐藏所有星星”的开关，亮星仍可保留。

这里的适应曲线是**显示映射**，不是人眼绝对感知模型。当前 RGB 三通道、
B−V proxy、黑体光谱和 PSF 都是明示的近似；不能据此宣称精确肉眼极限星等。
背景星场按点源显示，并未把整片银河作为额外大气照明源求解。

## 5. 验收

- `scripts/test_color.mjs` 检查黑体冷暖方向、B−V 色差、星等比和光度零点。
- `scripts/verify_photometry.py` 在真实 WebGL 中检查两模式颜色一致、恒星
  圆面/天空色差、白天关闭星场前后的像素差和夜间颜色。
- 夜间截图使用明确标注的浏览器内存光照控制，不修改观察点或世界存档。
- 当前 Νεφέλη 昼侧关闭背景星场前后的 RGB 平均像素差为 **0**；两种模式
  抽样的 200 颗 Hipparcos 星颜色最大差为 **0**。真实蓝星 HIP 25336
  （B−V = −0.224）在夜景中心的像素为 **[78,79,87]**，而非被洗成白色。
  Αστραία 圆面像素 **[255,234,217]**，天空为 **[120,158,211]**。
- 多次散射对照仍通过：开启高阶后像素 **[114,154,208]**，仅一阶为
  **[106,132,166]**。全部 140 项 Python 回归及完整 UI 验收通过。
